# AORebirth roadmap

Feature map for the AORebirth server: what works today and what is still to come, for Rubi-Ka and each expansion.

- **Player page:** https://mcandersdk.github.io/aorebirth-roadmap/
- **Issues:** each feature is an issue, grouped into epics (sub-issues) and milestones (Baseline or an expansion).
- **Board:** https://github.com/users/McAndersDK/projects/2

Statuses: open with no label = planned, `status: wip` = in development, `status: partial` = partly working,
`status: testing` = in testing, `status: blocked` = on hold, closed = live.

The page in `site/` is published by `.github/workflows/pages.yml`, which rebuilds `data.json` from the issues on every
issue change and once an hour.
